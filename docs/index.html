Call Center

Sachez si un collègue est en call avant de le déranger, et soyez prévenu quand il a fini.

curl -fsSL https://raw.githubusercontent.com/loicjazon/call-center/main/install.sh | sh

Sans sudo · installe dans ~/.local/bin · démarre à chaque ouverture de session

Voir sur GitHub Dernière version

Aperçu

Une liste de collègues favoris, un statut à jour quand vous l'ouvrez, et des cloches pour être prévenu.

Comment ça marche

Lecture seule : l'application ne publie rien dans Slack.

  1. À l'ouverture de la fenêtre, elle lit auprès de Slack la présence et l'état de huddle de vos favoris. Pendant la lecture, le statut s'affiche « inconnu » plutôt qu'une valeur périmée.
  2. Sur un collègue en call, un clic arme la cloche 🔔. Les collègues avec une cloche sont revérifiés chaque minute.
  3. Quand il sort du huddle, vous recevez une notification et la cloche se désarme.

Prérequis

  • Ubuntu 22.04 ou plus récent, avec un bureau graphique (GNOME testé) et l'extension « AppIndicator » (activée par défaut sur Ubuntu).
  • Une application Slack à vous, avec le droit users:read (User Token Scopes) : le jeton xoxp-… va dans ~/.config/call-center/token (chmod 600). Le README détaille les étapes.
  • Le « call » est un huddle Slack (y compris un appel entre deux personnes en message privé). Un appel Zoom, Teams ou Meet n'est visible que si l'outil met lui-même le statut Slack à jour.

Documentation complète, limites et développement : README.

Confidentialité : le jeton reste sur votre machine, les appels vers Slack sont en lecture seule, et rien n'est envoyé ailleurs (les avatars sont téléchargés sans le jeton).

Désinstaller : curl -fsSL https://raw.githubusercontent.com/loicjazon/call-center/main/install.sh | sh -s -- --uninstall
